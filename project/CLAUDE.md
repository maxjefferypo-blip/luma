# Luma — project instructions

- Brand tone of voice underpins every digital touchpoint. All copy (website, listings, social, email, packaging, UI microcopy) must follow `guidelines/voice/brand-strategy.md`. Check its claims and figures registers before writing any claim or number.
- Light technology is the central promise. Sleep and wellness are context only, never outcomes.
- When a figure or claim status changes (launch-readiness checklist, §9), update the registers in `brand-strategy.md` first, then every surface that uses it: `ui_kits/website/`, `templates/*`, `guidelines/voice/voice-figures.card.html` and `voice-claims.card.html`.
- Visual direction: Seed is a reference for quality and flow only. Never copy it.
