A single line icon (Lucide glyphs, 1.5px stroke). Use sparingly — arrows on CTAs, cart, menu, plus/minus, close.

```jsx
<Icon name="arrow-right" size={20} />
<Icon name="shopping-bag" size={24} title="Bag" />
```

- Always line, never filled. Colour follows text (`currentColor`).
- No icons as decoration beside headings or in feature lists.
