Rounded image container. Pass `src` for photography; omit it to show a flat placeholder with an art-direction caption.

```jsx
<MediaFrame src="/img/bedside.jpg" alt="Phone on a bedside table at dusk" ratio="16 / 9" radius="lg" />
<MediaFrame tone="mist" ratio="1 / 1" caption="LC–01 on Stone, raking daylight" />
```

- Photography: warm, natural light, calm interiors, soft shadow. No neon, no stock "tech" imagery.
