The luma wordmark (with eclipse). Use for every logo placement — headers, footers, packaging, social — never type "luma" in a font.

```jsx
<Logo height={28} />                    {/* header on Bone */}
<Logo variant="reversed" height={40} /> {/* on Charcoal */}
<Logo variant="wordmark" height={32} /> {/* one-colour: emboss, foil, mono print */}
```

- `height` drives size; width follows (ratio 2.832 : 1). Minimum 24px tall on screen.
- Clear space = the x-height of the wordmark (≈ 0.67 × `height`) on every side.
- Do not recolour, stretch, add effects, or move the eclipse. On photography, place only over calm, low-detail areas.
